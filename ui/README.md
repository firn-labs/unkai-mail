# Unkai Mail — UI

Svelte 5 + TypeScript + Vite frontend for the Unkai Mail Tauri app, styled with Tailwind v4 and Skeleton v5.

Before touching any component, read:

- [`docs/UI_CONVENTIONS.md`](../docs/UI_CONVENTIONS.md) — the authoritative design-language spec: hard rules, ban list, drift ledger.
- [`CLAUDE.md`](../CLAUDE.md) § "UI Conventions" and § "Sidebar-routed integration view shell" — behavioral idioms (menus, anchoring, dismissal, view-shell structure).
- [`icons/ICON_DESIGN_REFERENCE.md`](../icons/ICON_DESIGN_REFERENCE.md) — the icon drawing spec for everything in `src/lib/icons/`.

Development commands live in the root [`CLAUDE.md`](../CLAUDE.md) § "Build & Run" (`npm install` here, `npm run tauri dev` / `npm run tauri build` from the repo root).
